# Передача: «Траты» (money/) — контроль расходов

## Что это
Личное offline-first PWA, замена Monefy. Папка `money/` в репозитории `baklanov1993dmitry-gif/moi-dela` (ветка main → Cloudflare Pages, деплой автоматом после push).
- Прод: https://moi-dela-money.pages.dev
- Рабочая копия: `/home/claude/moi-dela` (в новом чате: клонировать репо заново через add_repo/gh)
- Один файл `money/index.html` (~165 КБ, inline JS/CSS) + `supabase-lib.js`, `sw.js`, `manifest.json`, иконки.
- Supabase проект `rjiuialimbrnbriqafjl`; вход тем же аккаунтом, что в «Моих делах» (`storageKey:"mytasks-auth"`). Таблицы `fin_categories` (есть колонка `lim` — личный лимит), `fin_tx`.
- viewport width=360 (1 css-px = 1 dp, как в Monefy).

## Правила работы с пользователем (Дмитрий, Новосибирск, UTC+7)
- Русский, дружески, с юмором, кратко. Можно мини-урок по теме.
- Про формат результата НЕ спрашивать: работаем в устоявшемся формате «правка → выкладка в main → краткий отчёт».
- Файл не показывать в чате целиком. Править точечно (python-патчи с assert на count==1 или Edit), после КАЖДОЙ правки: извлечь inline-JS и `node --check`.
- После изменений менять версию кэша в `money/sw.js` (сейчас `money-shell-v15`), иначе телефон покажет старое.
- Коммиты оканчивать строками Co-Authored-By / Claude-Session из системного напоминания.
- Любой экран проверять Playwright-ом (viewport 360×758, DSF 2, localStorage-фикстуры: `mytasks-auth`, `fin_cats_v1`, `fin_tx_v1`), смотреть скриншоты. Supabase в песочнице недоступен — мок/без сети.

## Данные и состояние
- localStorage: `fin_cats_v1`, `fin_tx_v1`, `fin_pend_v1` (очередь на отправку), `fin_sync_v1`, `fin_pref_v1` (PR — настройки), `fin_ext_v1` (EXT: шаблоны `tpl` и повторяющиеся `rec`, только локально).
- PR: `theme`, `acc` (акцент! не использовать для другого), `iset` (line/badge/emoji), `rn` (названия в колесе), `bm` (norm/cap/off), `cap` (потолок), `normN` (база нормы 3/6/12), `avg`, `acs` (раскрытые аккордеоны), `fixm` {месяц:{catId:true}} — закреплённые 🔒 ПО МЕСЯЦАМ, `cl` {месяц:{catId:true}} — закрытые на месяц, `srt` (режим сортировки), `hmN`, `topN`, `hb2`.
- Кэши в памяти: `monthSums()`, `mIdx()/ofMonth()` (индекс по месяцам), `PC` — кэш HTML страниц (`pageHTML(d)`), соседние месяцы строятся в простое (`prefetch`). Ключ кэша включает ui/PR/cats/txv — при новом состоянии, влияющем на HTML, добавлять в ключ.

## Что реализовано (кратко)
- Колесо расходов с иконками/названиями (кольцевые сектора через path `sect()`), список по категориям, сортировка (`catOrder`, 8 режимов, закрытые/закреплённые внизу), раскрытие группы, дробь факт/план с заливкой по близости к плану (`frStyle`).
- Свайп между месяцами (карусель: `carOpen/carNb/carEnd/slide`, зазор 28px, нет клипа), кнопки по бокам баланса: ⚡ быстрый ввод/шаблоны, справа «Сводка» (сегодня, можно потратить, прогноз, к тому же дню прошлого месяца, ближайшие повторы, последние траты); ⇄ в шапке — сравнение периодов.
- Бюджет: норма (среднее за N мес., только категории с тратами ≥ 2 мес.), потолок (`capPlan`: потраченное не урезается, 🔒 не урезается, остаток делится на гибкие; закрытые категории освобождают остаток), личные лимиты, ☑️ «закрыть на месяц».
- Аналитика — аккордеоны: бюджет, средние, календарь-теплокарта, динамика, дни недели (со суммами), категории по месяцам (3/6/12/год/прошлый год), крупные траты (месяц/3 мес/год/всё).
- Темы (серая, чёрная, светлая, синяя, лесная, сливовая, песок, кремовая, бежевая, мятная, небесная, розовая, лавандовая), 22 акцента, иконки Tabler (MIT) вместо самодельных.
- Шаблоны, повторяющиеся платежи (`runRec`), поиск при вводе траты, поиск категории, редкие категории скрыты.
- Чек по фото: 📷 → клиент ужимает до 1700px → Edge Function `receipt` (Supabase, задеплоена; Haiku 4.5 по умолчанию, переопределяется секретом `ANTHROPIC_MODEL_RECEIPT`; ключ `ANTHROPIC_API_KEY` уже в секретах) → экран подтверждения → запись по категориям. Исходник: `supabase/functions/receipt/index.ts`. Деплой — через дашборд Supabase (встроенный браузер), CLI нет.
- «Назад»: из списка → в колесо, из колеса — двойное нажатие для выхода. Мгновенный старт: первый кадр из localStorage, библиотека Supabase догружается после.

## Открытые вопросы / идеи
1. Баг «тап по балансу срабатывает со второго раза» — не воспроизвёлся; добавлена защита (`softRender` не перерисовывает при касании). Уточнить у пользователя при повторе.
2. Реальная проверка чека на настоящем фото (качество категорий Haiku 4.5); при слабом качестве — секрет `ANTHROPIC_MODEL_RECEIPT` = Sonnet.
3. Идеи: прогноз по категориям до конца месяца; уведомление при 80% лимита; «что-если»; недельный разбор; счета/переводы; перенос шаблонов/повторов в Supabase (если несколько устройств); больше иконок для категорий (сейчас 34 эмодзи → Tabler-значок).
4. Пользователь просил компактность/наглядность/читаемость в балансе — держать это правилом при любых новых экранах (одна строка факт/план, пояснения прячем в ⓘ).
