# План разработки «Мои дела» (идеи в очереди)

Правило: новую функцию сначала обсуждаем (набросок + 2–3 вопроса), код пишем после «делаю».

## 1. Аналитика: сколько задач рождается в списке «Работа» (запись 12.11)
Зачем: понять, насколько много новых задач прилетает в течение дня и недели.
- Показывать внутри «Мои дела», формат выдачи — обсудить (идея: отдельная сводка: по дням недели, по неделям, среднее в день, пик, сколько добавлено vs сколько закрыто).
- Данные: `tasks.created_at` по списку «Работа» (список ищется по /работ/i) — миграция не нужна. Ограничение: удалённые задачи в подсчёт не попадут (если нужно — вести журнал создания отдельно).
- Заодно: сделать кликабельными плашки недель («Эта / След. / +2 нед. / +3 нед.») над списком «Работа» — по клику показывать задачи этой недели (фильтр по сроку), возможно с переходом в сводку.
- Вопросы к обсуждению: считать по дате создания или по «рабочему дню»; нужна ли привязка к теме/исполнителю; где показывать (раздел меню «Работа» или кнопка в шапке списка).

## 2. Другое в очереди
- Голос «потратил …» → «Траты» (нужна схема таблиц «Трат»); «здоровье …» голосом.
- Руководитель: правка шагов/повторов/напоминаний у чужих задач (сейчас только название, срок, список, заметка).
- Расшифровка: словарь замен для имён/терминов (на ПК есть, на Android нет); при желании — ускорение/пересборка по итогам реальных записей.
