# Передача: «Мои дела» (корень репозитория) — личные дела, журнал, питание

## Что это
Личное PWA-приложение в корне репо `baklanov1993dmitry-gif/moi-dela` (main → Cloudflare Pages, автодеплой). Замена Microsoft To Do + журнал времени + питание + тренировки. Один большой файл `index.html` (~4400 строк, inline JS/CSS), `sw.js`, манифесты `manifest*.json`, `supabase-lib.js`.
- Рабочая копия: `/home/claude/moi-dela` (в новом чате клонировать репо).
- Supabase проект `rjiuialimbrnbriqafjl`. Миграции `migration_v5…v11.sql`, Edge Functions в `supabase/functions/` (analyze — ИИ-разбор, send-reminders, track, video, receipt — это для «Трат»). Секреты: ANTHROPIC_API_KEY, GEMINI_API_KEY и др.
- Кэш service worker: `moidela-shell-v24` (в `sw.js`) — менять при каждой выкладке.
- Подробности о приложении также в памяти пользователя: `/areas/moi-dela.md`, `/areas/personal-todo-app.md`, `/areas/zhelezo-workout-app.md` (читать первым делом).

## Правила работы с пользователем (Дмитрий, Новосибирск, UTC+7)
- Русский, дружески, с юмором, кратко. Мини-уроки допустимы.
- О формате результата не спрашивать (устоявшийся процесс: правка → push в main → краткий отчёт).
- Большой файл не показывать в чат. Держать правки точечными (python-патч с assert count==1 или Edit); после КАЖДОЙ правки извлечь самый длинный `<script>` и `node --check`.
- Коммиты оканчивать Co-Authored-By/Claude-Session из системного напоминания.
- Проверка: Playwright (`index.html` на локальном http.server); `ui`/`S` могут быть недоступны из evaluate (обёрнуты в замыкание) — тестировать через DOM-события или временно экспортировать.

## Архитектура (то, что нужно знать для правок)
- Глобальные `S` (данные: tasks, time_log, …), `ui` (состояние интерфейса), `render()` перерисовывает `#app` целиком и ВОССТАНАВЛИВАЕТ значение/курсор активного поля (`fid/fv`), поэтому перед render() очищать DOM-значение поля, если модель сброшена (из-за этого был баг «остаётся текст прошлого дела»).
- Действия: объект `acts` + делегирование `data-a="..."`; клавиши Enter — в `app.addEventListener("keydown")` (около `jr-tx`).
- Журнал времени (`jr*`): `jrState()`, `jradd`, `jrsave`, `jrplan`, колесо времени `jrWheelHTML` + `jrWStep/jrWCol` + глобальные wheel/keydown/mousedown обработчики. Ввод цифр: первая заменяет, вторая дополняет, после двух цифр в часах переход в минуты; активный столбец и подпись «часы/минуты» подсвечены.
- Питание (`nu*`), тренировки, ИИ-разбор (`analyze`).

## Что сделано в последнем чате
- Колесо времени: подсветка активного поля, авто-переход, клик по столбцу/подписи.
- Очистка поля «Что делал?» после записи (Enter) — поле очищается до render().
